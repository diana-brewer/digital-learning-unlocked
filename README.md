# Digital Learning Unlocked

Affordable Tools and Tech for Next-Gen APP Education

A 75-minute presentation and workshop for the 2026 APP Fellowship Conference by Diana Brewer, PA-C.

## Live Site

**Workshop Guide (share with attendees):** [https://diana-brewer.github.io/digital-learning-unlocked/](https://diana-brewer.github.io/digital-learning-unlocked/)

## Files

| File | Purpose |
|------|---------|
| `index.html` | Workshop Guide — the audience-facing page (this is the homepage) |
| `Digital Learning Unlocked - Slide Deck.pptx` | Slide deck for presenting |
| `Digital Learning Unlocked - Presenter Notes.html` | Facilitator guide with timing and scripts |
| `Digital Learning Unlocked - Workshop Guide.html` | Same content as index.html (original filename) |
| `workshop-case-demo.html` | Interactive clinical reasoning case demo |
| `workshop-branching-demo.html` | Branching clinical decision tree demo |

## How to Use

1. **Present from** the slide deck (.pptx) in Keynote or PowerPoint
2. **Share the live URL with attendees** — they open it on their phones: `https://diana-brewer.github.io/digital-learning-unlocked/`
3. **Follow the Presenter Notes** for timing, scripts, and facilitation guidance

## Setup

1. Push this repo to GitHub: `https://github.com/diana-brewer/digital-learning-unlocked`
2. Enable GitHub Pages: Settings → Pages → Source → main branch → /(root)
3. The `.nojekyll` file ensures GitHub Pages serves raw HTML without Jekyll processing

The site will be live at: `https://diana-brewer.github.io/digital-learning-unlocked/`
